# Rich the Mobile Mechanic

Lead-capture website for Rich's mobile auto repair service (Los Angeles). Next.js + Tailwind.

- `site/` - the Next.js app (`npm install`, `npm run build`, `npm run start`)
- `site/config/site.ts` - all business content; items marked PLACEHOLDER need real data (phone, email, hours, work photos, reviews)
- Set `NEXT_PUBLIC_GHL_FORM_URL` to the GoHighLevel form embed URL to replace the placeholder lead form
- `source-notes.md` and `source-assets/` - content scraped from the previous Square Online site
